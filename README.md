# River Crown — Web preview

Mobile browser preview of the existing River Crown Godot game.

Open **https://imhyunbae.github.io/river-crown-web/** in Safari, preferably on Wi-Fi for the initial download (about 145 MB before HTTP compression).

- Godot 4.7.2, Compatibility / WebGL 2, single-threaded WebAssembly.
- iOS 16.4 or newer is required by the compressed asset loader; a recent iOS release is recommended.
- Tap **건설**, select **집**, choose a position, then tap the checkmark to start construction. Drag empty ground to pan; pinch to zoom.
- Progress is stored in this browser. Private browsing and clearing website data can remove it.
- The web preview uses the game's existing lightweight water fallback. Vulkan-only procedural grass/flower effects are not available in this build.
- This repository contains the web distribution; the original native project is maintained separately.
